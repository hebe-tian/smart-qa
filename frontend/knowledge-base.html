操作指引
1. 在 GitHub / GitLab / Gitee 仓库页面，点击 Code → Download ZIP 下载源码压缩包
2. 私有仓库：先用你的账号克隆到本地，再压缩为 zip 即可
3. 输入文档标题后点击上方按钮，选择下载的 zip 文件上传
4. 系统自动解压提取代码文件（支持 .py .js .ts .java 等），跳过 node_modules 等无关目录
支持任意 Git 平台（GitHub / GitLab / Gitee / 自建），单文件不超过 1MB，最多 200 个文件，zip 不超过 50MB
