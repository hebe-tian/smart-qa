# AI 测试用例生成平台

> AI 驱动的测试用例生成平台 — 用户输入需求稿后，AI 自动分析需求、多轮问答补全上下文、拆分功能模块、生成结构化测试用例。支持选择性重新生成、AI 模型配置与连接测试、全链路调用记录与数据概览。

## 一、支持的功能

| 功能模块 | 描述 |
|----------|------|
| **需求管理** | 创建/编辑/删除需求，支持分页查询与搜索过滤，按状态（draft/analyzing/qa/generating/completed）流转 |
| **AI 需求分析** | AI 自动分析需求稿，识别歧义与缺失细节，生成追问问题列表 |
| **多轮问答补全** | 聊天式交互界面，AI 每轮最多追问 2 个问题，用户回答后 AI 判断上下文是否充分，充分后自动进入生成阶段 |
| **模块拆分生成** | AI 基于需求+QA 上下文，拆分出 3-8 个功能模块，每个模块包含名称、描述和关键测试点 |
| **测试用例生成** | 逐模块生成 3-8 条结构化测试用例，覆盖功能、边界、异常、性能四类，含前置条件、步骤、预期结果、优先级 |
| **选择性重新生成** | 勾选不满意的用例/模块，填写原因与补充描述，AI 基于原内容+新指令重新生成，保存新旧快照 |
| **AI 模型配置** | 多模型管理，支持 OpenAI 兼容 API，API Key 加密存储，一键连接测试 |
| **全链路调用记录** | 每次 AI 调用全量记录：prompt/response/token 用量/耗时/状态，可展开查看完整详情 |
| **数据概览** | 统计卡片（用例总数/生成次数/AI 调用次数/token 消耗/成功率）、token 趋势图表、事件流 |
| **用户行为埋点** | 前后端双端埋点，追踪 page_view/click/generate_start/generate_complete/regenerate/qa_round/config_test/login/logout 等事件 |
| **用户认证** | JWT Token 认证，用户注册/登录，密码 bcrypt 哈希存储；初始管理员账密支持 ADMIN_USERNAME / ADMIN_PASSWORD 环境变量自定义 |
| **游客模式** | 登录页一键"游客访问"，免登录只读浏览需求管理/需求详情/问答/数据概览；AI配置、调用记录、知识库、SOP 等敏感页面对游客隐藏，后端统一拦截游客写操作（403），前后端双重防护 |
| **用例导出** | 需求详情页一键导出全部模块与用例，支持 HTML / Markdown / XMind 三种格式，浏览器自动下载 |
| **RAG 知识库** | 向量嵌入检索历史用例，AI 生成时注入相似案例作为 few-shot 参考，提升用例覆盖度与一致性；支持知识库状态查看、问答查询、索引重建 |
| **项目类型区分** | 需求区分线上项目（production）与测试项目（test），仅线上项目数据纳入知识库索引 |
| **Embedding 模型配置** | AI 配置支持 chat/embedding/both 三种类型，可独立配置 Embedding 模型与 API |

## 二、项目特点

1. **多轮问答补全**：AI 分析需求后自动生成追问，用户多轮回答直到上下文充分，聊天式交互界面带打字机效果
2. **选择性重新生成**：勾选不满意的用例/模块，填写原因描述，AI 基于原内容+新指令异步重新生成，完整记录调用日志
3. **AI 模型灵活配置**：支持 OpenAI / 智谱 / 通义 / Moonshot / DeepSeek 等兼容 API，多模型管理 + 一键连接测试
4. **Prompt 链分步生成**：模块拆分 → 逐模块生成用例，后台线程异步执行 + 前端轮询进度
5. **全链路调用记录**：每次 AI API 调用全量记录（prompt/response/token/耗时/状态），可展开查看详情
6. **用户行为埋点**：前后端双端埋点，统计卡片 + 趋势图表 + 事件流实时展示

## 三、技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | Flask 3.0+ |
| ORM | Flask-SQLAlchemy 3.1+ / SQLAlchemy 2.0+ |
| 数据库 | SQLite (WAL 模式) |
| AI SDK | openai 1.10+ (Python SDK) |
| 认证 | PyJWT 2.8+ (JWT Token) |
| 加密 | cryptography 42+ (Fernet) |
| JSON 容错 | json-repair 0.3+ |
| 向量计算 | numpy 1.26+ / scikit-learn 1.5+ |
| 跨域 | flask-cors 4.0+ |
| 前端 | 原生 HTML + CSS + JavaScript (ES6+) |
