# 多轮问答知识库系统 — 操作指南

---

## 1. 开始新问答会话

1. 点击侧边栏"知识库问答"进入页面
2. 默认显示"问答对话"视图
3. 点击左侧"新建问答"按钮，创建新会话
4. 在右侧底部输入框输入问题，点击"发送"

---

## 2. 回答 AI 追问

1. 提问后，AI 会自主判断问题是否清晰
2. 若不清晰，AI 会发送追问消息（浅黄色气泡），请根据提示补充信息
3. 若清晰，AI 直接给出答案（白色气泡）
4. 可多轮问答，直到问题解决（3 轮后 AI 强制给出答案）

---

## 3. 给出反馈

1. AI 给出答案后，答案气泡底部显示"准确"和"不准确"两个按钮
2. 若回答正确：点击"准确"，可附评论；该问答会**自动纳入知识库索引**，后续提问可检索到
3. 若回答有误：点击"不准确"，附评论说明问题；该问答**不会**纳入知识库，避免污染

---

## 4. 查看历史会话

1. 左侧会话列表显示所有历史会话
2. 每张卡片显示标题、时间、状态标签（追问中 / 已回答 / 已反馈）
3. 点击会话卡片，右侧加载完整对话内容
4. 可删除不需要的会话（点击卡片删除按钮）

---

## 5. 管理代码源（本地上传）

1. 在知识库页面顶部点击"代码源管理"Tab
2. 在左侧"本地上传"区域：
   - 点击虚线拖拽框或"选择文件"按钮
   - 选择代码文件（.py/.java/.js 等 28 种语言）
3. 系统自动提取代码、按函数/class 分块、向量化索引

---

## 6. 管理代码源（GitHub 拉取）

1. 在"代码源管理"Tab，右侧"GitHub 拉取"区域：
   - 输入 GitHub 文件的 raw URL
   - 输入标题和描述
   - 点击"拉取"按钮
2. 系统从 GitHub 拉取代码内容并自动索引

---

## 7. 管理代码文档列表

1. 在"代码源管理"Tab 下方查看已导入的代码文档列表
2. 表格显示：标题、语言、来源、分块数、索引状态
3. 可删除单个代码文档
4. 可对文档重建索引
