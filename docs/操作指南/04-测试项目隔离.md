# 测试项目隔离 — 操作指南

---

## 1. 创建需求时选择项目类型

1. 在需求列表页点击"新建需求"
2. 在创建弹窗中，选择项目类型：
   - **线上项目**：正式需求，数据纳入知识库索引，AI 生成用例时可参考历史数据
   - **测试项目**：测试用途，数据不纳入知识库，不影响线上生成质量
3. 默认为"线上项目"
4. 点击"保存"

---

## 2. 按项目类型筛选

1. 在需求列表页工具栏，找到项目类型筛选下拉
2. 选择：全部 / 线上项目 / 测试项目
3. 列表立即刷新，只显示对应类型的需求卡片
4. 每张卡片左上角显示类型徽章（线上项目 / 测试项目），便于快速识别

---

## 3. 查看需求的项目类型

1. 在需求详情页，需求信息区的标题旁显示项目类型徽章
2. 可直观了解当前需求属于线上还是测试项目

---

## 4. 将测试项目切换为线上项目

1. 测试项目验收通过后，在需求详情页可操作切换
2. 切换为线上项目后，该项目的需求/模块/用例数据将被纳入知识库索引
3. 需重建知识库索引使新数据生效

---

## 5. 查看知识库数据分类

1. 进入知识库问答页面
2. 顶部状态栏分别显示：
   - "线上数据 N 条"
   - "测试数据 N 条"
3. 可直观了解知识库的数据来源构成
