# 用例导出功能 — 操作指南

---

## 1. 进入导出入口

1. 在需求列表页点击需求卡片进入详情页
2. 确保需求状态为"已完成"且有生成的模块和用例
3. 切换到"模块用例"标签页
4. 在工具栏右侧找到"导出"按钮（与"重新生成"按钮并列）

> 若无模块/用例数据，导出按钮为禁用状态。

---

## 2. 选择导出格式

1. 点击"导出"按钮，展开下拉菜单
2. 菜单显示 4 个选项：

| 格式 | 说明 | 适用场景 |
|------|------|----------|
| HTML | 自包含网页，含表格样式 | 浏览器直接打开查看，分享给非技术人员 |
| Markdown | 纯文本格式，H1/H2/H3 + 表格 | 粘贴到文档系统、Wiki、GitHub |
| XMind | 思维导图文件 | 导入 XMind 软件查看用例树结构 |
| Excel | .xlsx 表格，表头加粗带背景色 | 团队协作、测试管理系统导入 |

3. 点击目标格式选项

---

## 3. 下载文件

1. 选择格式后，浏览器自动开始下载
2. 文件名格式：`{需求标题}_{日期}.{扩展名}`
3. 下载完成后可在本地打开查看

---

## 导出内容说明

导出范围为当前需求下的**所有模块及其全部用例**，包含以下字段：

- 模块名称
- 用例标题
- 优先级（高/中/低）
- 用例类型（功能测试/边界测试/异常测试等）
- 前置条件
- 测试步骤
- 预期结果
