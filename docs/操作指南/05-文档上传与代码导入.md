# 文档上传与代码导入 — 操作指南

---

## 1. 下载仓库 ZIP

从 Git 平台下载代码仓库的 ZIP 压缩包：

- **GitHub**：仓库页面 → `Code` 按钮 → `Download ZIP`
- **GitLab**：仓库页面 → 下载图标 → `Download source code`
- **Gitee**：仓库页面 → `克隆/下载` → `下载 ZIP`
- **私有仓库**：同样方式下载，无需平台访问外部仓库

---

## 2. 上传 ZIP 到平台

1. 点击侧边栏"知识库问答"进入页面
2. 点击顶部"代码源管理"Tab
3. 在 ZIP 上传区：
   - 输入文档标题（必填，如"用户服务后端代码"）
   - 输入描述（可选，如"v2.3.0 版本完整代码"）
   - 点击"选择 ZIP 文件上传"按钮
   - 选择本地 `.zip` 文件（最大 50MB）
4. 上传后系统自动：
   - 解压 ZIP 文件
   - 按扩展名白名单提取代码文件（.py/.js/.ts/.java 等 28 种）
   - 跳过 `node_modules`/`.git`/`__pycache__` 等目录
   - 按函数/class 边界分块并向量化索引

---

## 3. 查看已导入的代码文档

1. 在"代码源管理"Tab 下方查看代码文档列表
2. 表格显示：标题、语言、来源标签（上传）、分块数、索引状态
3. 一次 ZIP 上传可创建多条 CodeDocument（每个代码文件一条）

---

## 4. 管理代码文档

1. **删除**：点击列表中某条文档的"删除"按钮，移除单个代码文件
2. **重建索引**：对某条文档点击"重建索引"按钮，重新分块和向量化

---

## 注意事项

- 仅支持 `.zip` 格式，不支持 `.rar` / `.7z` / `.tar.gz`
- ZIP 内单文件限制 1MB，总文件数限制 200 个
- 非代码文件（图片、二进制、配置文件）自动跳过
- 上传成功后无需手动重建索引，系统自动完成索引
