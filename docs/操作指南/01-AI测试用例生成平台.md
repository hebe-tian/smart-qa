# AI 测试用例生成平台 — 操作指南

---

## 1. 登录

1. 打开平台首页（`http://127.0.0.1:5000`）
2. 输入用户名和密码（默认：`admin` / `admin123`）
3. 点击"登录"按钮，成功后跳转到需求列表页

---

## 2. 创建需求

1. 在需求列表页点击"新建需求"按钮
2. 在弹窗中输入需求标题和需求稿内容
3. 选择项目类型（线上项目 / 测试项目，默认线上）
4. 点击"保存"，需求以"草稿"状态出现在列表中

---

## 3. 多轮问答补全

1. 在需求列表页点击需求卡片进入详情页
2. 点击"AI 分析"按钮，AI 开始分析需求内容
3. 分析完成后，若 AI 认为需求不明确，会在"问答"标签页自动生成追问问题
4. 在底部输入框输入回答，点击"发送"
5. 重复问答，直到 AI 判定上下文充分，提示可进入生成阶段

---

## 4. 生成测试用例

1. 问答完成后，点击"生成模块"按钮（或"生成用例"一键生成全部）
2. 切换到"生成进度"标签页，查看实时进度条和状态文字
3. 生成完成后，切换到"模块用例"标签页查看树形结构
4. 点击模块节点展开/折叠，点击用例查看右侧详情卡片

---

## 5. 选择性重新生成

1. 在"模块用例"标签页，勾选需要重新生成的用例或模块
2. 点击"重新生成"按钮
3. 在弹窗中填写重新生成原因（必填）和描述需求（必填）
4. 点击"确认重生成"，AI 基于原内容 + 新指令重新生成并替换

---

## 6. 配置 AI 模型

1. 点击左侧侧边栏"AI 配置"进入配置页
2. 点击"新增模型"按钮
3. 填写：名称、Base URL、API Key、模型名、温度（滑块）、最大 Token
4. 可勾选"设为默认"
5. 点击"保存"
6. 点击"测试"按钮验证连接：显示加载 → 成功（绿色徽章）或失败（红色徽章 + 错误信息）
7. 已有模型可在表格中编辑、测试、删除

---

## 7. 查看调用记录

1. 点击左侧侧边栏"调用记录"
2. 使用筛选栏按任务类型、状态、时间范围筛选
3. 点击表格行展开，查看完整的 prompt 消息和 AI 响应内容
4. 查看每次调用的 Token 消耗和耗时

---

## 8. 查看数据概览

1. 点击左侧侧边栏"数据概览"
2. 查看统计卡片：用例总数、生成次数、AI 调用次数、总 Token 消耗
3. 查看图表：Token 消耗趋势（折线）、调用成功率（环形）、用例生成量（柱状）
4. 查看最近事件流，了解平台最新动态
