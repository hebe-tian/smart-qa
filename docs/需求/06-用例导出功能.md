# 用例导出功能 — 需求文档

> **来源 plan**：`用例导出功能_ff43b5a9`

---

## 需求概述

在需求详情页的"模块用例"标签页中，增加测试用例导出功能，支持导出为 HTML、Markdown、XMind、Excel 四种格式。用户点击"导出"按钮后弹出格式选择下拉菜单，选择格式后浏览器自动下载对应文件。

---

## 核心功能

### 导出按钮

- 在模块用例树标签页工具栏增加"导出"下拉按钮，与现有"重新生成"按钮并列
- 点击展开下拉菜单，包含 4 个格式选项：HTML、Markdown、XMind、Excel
- 每个选项带格式图标和说明文字
- 点击外部自动收起菜单

### 导出范围

- 导出当前需求下的**所有模块及其用例**（完整数据）
- 无模块/用例时禁用导出按钮并提示

### 四种导出格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| HTML | `.html` | 自包含 HTML 页面，含内联 CSS 表格样式，可直接在浏览器打开 |
| Markdown | `.md` | 需求标题为 H1，模块为 H2，用例为 H3，用例详情用表格展示 |
| XMind | `.xmind` | 思维导图：中心主题=需求标题 → 一级分支=模块 → 二级分支=用例标题，详情放入 topic notes |
| Excel | `.xlsx` | 单工作表，列：模块/用例标题/优先级/类型/前置条件/测试步骤/预期结果，表头加粗带背景色 |

---

## 边界约束

- 仅当需求状态为 completed 且存在模块数据时可导出
- 导出文件名格式：`{需求标题}_{日期}.{扩展名}`
- 支持中文文件名
