# AI 测试用例生成平台 — 需求文档

> **来源 plan**：`ai-smart-qa-platform-flask-v2_105f333c`（最终实现版本）

---

## 产品概述

一个 AI 驱动的测试用例生成平台，用户输入需求稿后，AI 自动分析需求、拆分功能模块、生成结构化测试用例。平台按照"需求-模块-用例"三层维度组织数据，支持多轮问答补全需求、选择性重新生成、后台 AI 模型配置与连接测试。

---

## 核心功能

### 需求管理

- 创建/编辑需求，文本输入需求稿内容
- 状态跟踪：草稿 → 分析中 → 问答中 → 生成中 → 已完成
- 需求列表页支持搜索和状态筛选

### 多轮问答补全

- AI 分析需求后若存在不明确点，自动生成追问问题
- 用户多轮回答补全信息，直到 AI 判定上下文充分
- 聊天式界面，AI 气泡 + 用户气泡 + 打字机效果

### AI 生成用例

- 基于需求 + 问答上下文，AI 自动拆分功能模块
- 逐模块生成结构化测试用例（标题、前置条件、操作步骤、预期结果、优先级、用例类型）
- 生成过程异步执行，前端实时展示进度

### 选择性重新生成

- 勾选已生成的用例或模块
- 填写重新生成原因和描述需求
- AI 基于原内容 + 新指令重新生成并替换

### AI 模型配置

- 后台配置 AI 模型（名称、Base URL、API Key、模型名、温度、最大 Token）
- 支持测试连接状态（已连通/未连通）
- 可配置多个模型并设默认

### 调用记录查看

- 查看 AI 调用历史（时间、任务类型、模型、状态、Token 消耗、耗时）
- 支持按任务类型、状态、时间范围筛选
- 行可展开查看完整 prompt 和 response

### 数据概览

- 统计卡片：用例总数、生成次数、AI 调用次数、总 Token 消耗
- 图表：Token 消耗趋势（折线）、调用成功率（环形）、用例生成量（柱状）
- 最近事件流：最新 10 条事件列表

## 页面规划

### 页面 1：登录页（index.html）

- 品牌区：居中 Logo + 平台名称"AI 用例生成平台" + 简短描述，渐变背景
- 登录表单：玻璃态卡片，用户名/密码输入框 + 登录按钮
- 默认账号：admin / admin123

### 页面 2：需求列表页（dashboard.html）

- 顶部导航栏：Logo + 面包屑 + 用户头像 + 退出
- 左侧侧边栏：导航菜单（需求管理 / AI 配置 / 调用记录 / 数据概览）
- 操作栏：新建需求按钮 + 搜索框 + 状态筛选
- 需求卡片列表：标题 / 状态徽章 / 模块数 / 用例数 / 创建时间 / 操作按钮

### 页面 3：需求详情页（requirement.html）— 核心页面

- **需求信息区**：标题 / 内容 / 状态标签 / 操作按钮（AI 分析 / 生成模块 / 生成用例）
- **Tab1 问答面板**：聊天式界面，AI 气泡（蓝灰）+ 用户气泡（白色）+ 输入框 + 发送按钮
- **Tab2 生成进度面板**：进度条 + 脉冲动画 + 状态文字"正在生成模块 → 用例"
- **Tab3 模块用例树**：左侧树形结构（展开折叠 + 勾选）+ 右侧详情卡片
- **重生成弹窗**：原因输入框 + 描述需求文本域 + 确认按钮

### 页面 4：AI 配置页（ai-config.html）

- 模型列表表格：名称 / Base URL / 模型名 / 状态徽章 / 默认星标 / 操作
- 新增/编辑表单：名称 / Base URL / API Key / 模型名 / 温度滑块 / 最大 Token / 设默认开关
- 连接测试区：测试按钮 + 加载 → 成功绿色 / 失败红色 + 错误信息

### 页面 5：调用记录页（call-logs.html）

- 筛选栏：任务类型下拉 + 状态下拉 + 时间范围选择 + 搜索
- 调用记录表格：时间 / 任务类型 / 模型 / 状态 / Token 消耗 / 耗时
- 行可展开查看完整 prompt 和 response
- 分页控件

### 页面 6：数据概览页（analytics.html）

- 统计卡片行：用例总数 / 生成次数 / AI 调用次数 / 总 Token 消耗
- 图表区：Token 消耗趋势（折线）+ 调用成功率（环形）+ 用例生成量（柱状）
- 最近事件流：最新 10 条事件列表
