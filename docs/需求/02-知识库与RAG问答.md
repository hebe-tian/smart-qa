# 知识库与 RAG 问答 — 需求文档

> **来源 plan**：`知识库与RAG功能_a7caa4d2`

---

## 产品概述

基于现有需求/模块/用例数据搭建知识库，实现 RAG（检索增强生成）问答功能。用户可在知识库页面用自然语言提问，系统从历史需求、模块、测试用例中检索最相关内容，结合 AI 生成回答，并展示引用来源。

---

## 核心功能

### 知识库问答

- 用户在知识库页面用自然语言提问
- 系统从历史需求、模块、测试用例中检索最相关内容
- AI 结合检索结果生成回答
- 回答下方展示引用来源卡片（类型标签、来源标题、相似度分数）

### 索引管理

- 查看索引状态（已索引条数、最后构建时间、是否就绪）
- 一键重建索引

### Embedding 模型配置

- AI 配置页新增 Embedding 模型输入框（如 text-embedding-3-small）
- 留空时知识库功能不可用，前端显示提示
- 复用现有 AI 配置的 API Key 和 Base URL

---

## 页面规划

### 知识库问答页（knowledge-base.html）

与现有页面设计语言一致（深色侧边栏 + 浅色主内容区），聊天式问答为核心交互，分三个区域：

- **顶部状态栏**：索引状态（已索引 N 条 / 最后构建时间）+ 重建索引按钮
- **中间对话区**：用户消息气泡（右对齐主色调）+ AI 回答气泡（左对齐浅灰背景）+ 引用来源可折叠卡片
- **底部输入区**：提问输入框 + 发送按钮

### AI 配置页改动

在现有表单中新增 Embedding 模型输入框，不单独设计页面。
