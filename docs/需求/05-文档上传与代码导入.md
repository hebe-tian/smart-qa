# 文档上传与代码导入 — 需求文档

> **来源 plan**：`文档上传解析入库___文件夹代码导入RAG_58bdeb8a`

---

## 用户需求

将业务代码导入从 GitHub 单文件拉取模式改为 **ZIP 上传模式**。用户从任意 Git 平台（GitHub / GitLab / Gitee / 私有仓库）自行下载仓库 ZIP 文件后一次性上传到平台，服务端自动解压、提取代码文件并批量索引。一次上传即可导入整个仓库的所有代码文件，兼容所有 Git 平台和私有仓库。

---

## 核心功能

### ZIP 文件上传

- 支持上传 `.zip` 格式的仓库压缩包，最大 50MB
- 上传时需填写文档标题（必填）和描述（可选）

### 自动代码提取

- 解压后按编程语言扩展名白名单过滤（.py/.js/.ts/.java 等 28 种）
- 自动跳过 `node_modules`/`.git`/`__pycache__`/`.venv`/`dist`/`build` 等目录
- 保留 relative_path 目录结构信息

### 操作指引

- 页面上展示从 GitHub/GitLab/Gitee 下载 ZIP 的步骤说明
- 3 步引导：下载 ZIP → 输入标题 → 点击上传

### 代码文档列表管理

- 表格显示：标题 / 语言 / 来源 / 分块数 / 索引状态 / 操作
- 支持删除单个代码文档
- 支持重建索引
- 来源标签根据 source_type 动态显示（上传 / GitHub / 本地）
