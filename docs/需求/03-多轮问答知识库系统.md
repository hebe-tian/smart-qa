# 多轮问答知识库系统 — 需求文档

> **来源 plan**：`kb-qa-system_7b3b7b9a`

---

## 产品概述

在现有 RAG 单轮问答基础上，构建多轮问答知识库系统，实现知识库自学习闭环：用户提问 → AI 自主判断是否追问 → 给出解答 → 用户反馈 → 仅正面反馈的问答自动纳入索引供后续检索。

---

## 核心功能

### 多轮问答对话

- AI 自主分析问题清晰度，模糊时主动追问，清晰时直接回答
- 无固定追问轮次上限，3 轮后强制给出答案
- 对话以会话形式持久化，可查看历史会话
- 追问消息和答案消息视觉区分（追问浅黄色气泡，答案白色气泡）

### 代码源管理

- **本地上传**：支持上传代码文件（.py/.java/.js 等 28 种语言）
- **GitHub 拉取**：通过 raw URL 拉取代码文件内容
- 代码按函数/class 边界分块后向量化索引
- 代码文档列表管理（标题 / 语言 / 来源 / 分块数 / 状态 / 删除操作）

### 反馈机制

- AI 给出答案后，用户可标记"准确"或"不准确"并附评论
- 仅"准确"的问答触发自动索引，纳入知识库供后续检索
- 标记准确后显示"已纳入知识库"提示
- 避免"不准确"的问答污染知识库

### 会话历史

- 左侧会话列表，每张卡片显示标题、时间、状态标签（追问中/已回答/已反馈）
- 可查看、删除历史会话
- 选中会话后右侧加载完整对话内容

## 页面规划

### 知识库问答页（改造现有 knowledge-base.html）

**顶部 Tab 栏**：横向 Tab 切换"问答对话" | "代码源管理"，选中态底部高亮条。

**问答对话视图（双栏布局）**：

- **左侧会话列表**（280px 固定）：顶部"新建问答"按钮，下方会话卡片列表（标题/时间/状态标签），支持删除
- **右侧聊天区域**（自适应）：上部消息流（用户右对齐深色气泡 + AI 左对齐浅色气泡），答案底部显示反馈按钮组和来源折叠区；下部输入框 + 发送按钮

**代码源管理视图（Tab 切换后）**：

- **上方左右并列**：左侧"本地上传"区（虚线拖拽框 + 点击选择文件），右侧"GitHub 拉取"区（URL 输入框 + 标题/描述输入 + 拉取按钮）
- **下方代码文档列表**：表格显示标题/语言/来源/分块数/状态/操作，支持删除和重建索引
